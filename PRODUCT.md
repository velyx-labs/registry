# Product

## Register

brand

## Users

Laravel developers (intermediate to senior) building web applications. Context: evaluating component libraries during development, need to quickly assess whether Velyx is worth integrating. Primary job: find production-ready Blade components that don't create vendor dependency or abstraction overhead.

## Product Purpose

Velyx delivers a library of UI components for Laravel projects in copy-paste style, inspired by shadcn/ui. Components land in the user's codebase as source files — not as installed packages. Exists because the Laravel/Blade ecosystem lacked a shadcn-equivalent: beautiful, accessible, ownable components.

## Brand Personality

Precise. Honest. Craftsman. Speaks to developers who have been burned by "magic" before. No hype, no marketing — the product quality is the pitch. Tone mirrors the ethos of the product itself: you see everything, nothing is hidden.

## Anti-references

No strong anti-references stated. Avoid: generic SaaS landing templates (icon + title + body card grids), neon/cyberpunk dark aesthetics, corporate enterprise styling (navy + gold + stock photos), sterile white minimalism with zero texture or character.

## Design Principles

1. Practice what you preach — the landing uses the components it ships
2. Show the work — real CLI output and code do the selling, not marketing copy
3. Earned trust — confident and direct, not persuasive or hyped
4. Developer-native aesthetic — feels like a tool built by someone who uses tools
5. Shadcn typography sensibility — clean, weight-driven hierarchy, tight tracking on headings
